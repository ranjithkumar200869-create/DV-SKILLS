# Week 10: House Price Visualization, Spatial Analytics & Real-Estate Insights

## DESCRIPTION

This project focuses on visualizing and analyzing the King County House Sales dataset using Python. It explores house prices based on living area, property grade, condition, waterfront access, location, and renovation status.

## OBJECTIVES

- Analyze living area and house price relationships.
- Compare prices by property grade and condition.
- Analyze waterfront and non-waterfront house prices.
- Visualize geographical house price patterns.
- Compare property age and renovation status.
- Analyze price per square foot and feature correlations.

## WORKFLOW

**1. Load Dataset**
- Load the preprocessed CSV file using Pandas.
- Display the first five rows and statistical summary.

**2. Data Visualization**
- Create scatter plots for living area and house price.
- Create box plots for grade, condition, and waterfront access.
- Visualize house prices using latitude and longitude.

**3. Property Analysis**
- Analyze property age and renovation status.
- Compare average price per square foot across property grades.
- Create a correlation heatmap.

**4. Real-Estate Insights**
- Identify relationships between house prices and property characteristics.
- Compare property valuations across different locations.
- Summarize the results using charts and statistical values.

## TECHNOLOGIES USED

- Python
- Pandas
- Matplotlib
- Seaborn

## DATASET

**Dataset Name:** King County House Sales Dataset

**Input File:** `cleaned_kc_house_data.csv`

## OUTPUT

The project generates visualizations and statistical summaries to understand house price variations and geographical pricing patterns.

## CONCLUSION

This project uses data visualization and spatial analysis to understand house price trends. The insights help compare property characteristics and support further real-estate market analysis.
