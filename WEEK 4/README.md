# Apple Stock Data Visualization

## Project Overview

This project is used to **analyze and visualize Apple (AAPL) stock data** using Python.

The project mainly focuses on stock prices, trading volume, and moving averages.

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab

## Dataset

The dataset used is **AAPL.xlsx**.

It contains Apple stock information such as:

* Date
* Open
* High
* Low
* Close
* Volume

## Steps Performed

### 1. Import Libraries

Pandas, Matplotlib, and Seaborn are imported.

### 2. Load Dataset

The `AAPL.xlsx` file is loaded using Pandas.

### 3. Check Data

The project displays:

* First few rows
* Last few rows
* Column names
* Data types

### 4. Convert Date

The Date column is converted into datetime format.

### 5. Sort Data

The stock data is sorted based on the Date.

### 6. OHLC Price Analysis

A line chart is created for:

* Open price
* High price
* Low price
* Close price

This helps to understand the changes in Apple stock prices over time.

### 7. Volume Analysis

A line chart is created to show the **trading volume** over time.

### 8. 20-Day Moving Average

A **20-day moving average** is calculated using the Close price.

### 9. 50-Day Moving Average

A **50-day moving average** is calculated using the Close price.

## Conclusion

This project helps to understand **Apple stock price movements and trading volume** using Python visualization techniques.

Moving averages are also calculated to observe the stock price trend.
