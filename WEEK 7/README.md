# Student Performance Data Analysis

## Project Overview

This project is about **analyzing student performance using Python**.

The main aim is to clean categorical data and calculate basic statistical measures for student scores.

## Tools Used

* Python
* Pandas
* Google Colab

## Dataset

The dataset used is **StudentsPerformance.csv**.

It contains information about:

* Gender
* Race/Ethnicity
* Parental Level of Education
* Lunch
* Test Preparation Course
* Math Score
* Reading Score
* Writing Score

## Steps Performed

### 1. Load Dataset

The dataset is loaded using Pandas.

### 2. Clean Categorical Data

The categorical columns are cleaned by:

* Removing extra spaces
* Converting text into title case

### 3. Select Score Columns

The following subject scores are selected:

* Math Score
* Reading Score
* Writing Score

### 4. Calculate Statistical Measures

For each subject, the following are calculated:

* **Mean** – Average score
* **Median** – Middle value
* **Mode** – Most repeated score

## Conclusion

This project helps to understand **student performance using basic Python data analysis**.

The categorical data is cleaned and statistical measures are calculated for Math, Reading, and Writing scores.
